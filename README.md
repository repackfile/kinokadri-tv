# KinoKadri TV

KinoKadri-ს აპლიკაცია Android TV-სთვის (Android 7.0+), პულტით სამართავი.

## დაყენება

1. ჩამოტვირთეთ ბოლო ვერსიის `.apk` გვერდიდან [Releases](https://github.com/repackfile/kinokadri-tv/releases/latest).
2. ტელევიზორზე ჩართეთ „უცნობი წყაროები" (პარამეტრები → უსაფრთხოება და შეზღუდვები).
3. დააყენეთ APK.

## განახლება

აპი ახალ ვერსიას აქედან თავად პოულობს: გაშვებისას გამოჩნდება ფანჯარა „ახალი ვერსია",
ან პარამეტრებში დააჭირეთ „განახლების შემოწმებას".
